# Third-party dependencies and attribution

This project references tools such as Claude Code, SuperClaude, Superpowers, Ralph, Claude Map, Obsidian, Serena, Playwright, Context7, and other provider plugins/MCP servers.

**References are not claims of ownership or permission to redistribute.** Every redistributed upstream asset must have its precise source, version/ref, copyright attribution and license checked before release. The optional Claude Map extension must preserve attribution and licensing to the original Claude Map project.

The repository's authored rules, scripts, templates and documentation are distinct from upstream packages. Use installation manifests and official provider installation paths rather than uploading third-party caches.

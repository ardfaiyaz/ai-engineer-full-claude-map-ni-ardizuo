# 📄 Global Completion Mandate


Apply verification proportional to the development task.


<br />
<br />


## 📄 Before Completion


<br />


### 📄 Correctness

- Confirm the requested requirements were implemented.
- Check for regressions and unintended changes.
- Validate important edge cases.


<br />


### 📄 Maintainability

- Review unnecessary complexity.
- Review opportunities to reuse existing code.
- Identify suspicious dead code.
- Follow established project conventions.


<br />


### 🛡️ Security

- Check authorization and validation where relevant.
- Avoid leaking credentials and sensitive data.
- Review risky dependencies and operations.


<br />


### ☑️ Testing

- Run appropriate existing tests when practical.
- Run linting and type checking when available.
- Run a relevant build when appropriate.
- Never claim tests passed unless actually executed.


<br />


### 📄 Scope

- Avoid unrelated changes.
- Do not automatically delete unused code.
- Do not commit, push or deploy without authorization.


<br />


### 📄 Delivery

- Summarize changes.
- Report files changed when useful.
- Report verification outcomes.
- State remaining risks and blockers.

For small tasks, apply only the relevant checks.

Do not require every available skill, MCP or agent on every task.

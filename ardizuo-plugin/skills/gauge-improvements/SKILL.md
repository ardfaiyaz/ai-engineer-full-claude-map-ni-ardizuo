# 📄 Gauge Improvements

This is an original local development-focused adapter, not an official third-party skill.

Define measurable success criteria before implementation. Choose project-relevant metrics (tests, build size, type errors, user flow performance, code duplication). Collect a baseline. Make focused changes, remeasure, report actual numbers and caveats. Do not invent scores.

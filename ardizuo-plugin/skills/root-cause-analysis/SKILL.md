# 📄 Root Cause Analysis

This is an original local development-focused adapter, not an official third-party skill.

Use the existing systematic-debugging skill if available. Record actual symptoms, reproduction, hypotheses and disconfirming evidence. Find the first causative event; do not rely on correlation. Develop a targeted fix and regression test. Document remaining uncertainty.

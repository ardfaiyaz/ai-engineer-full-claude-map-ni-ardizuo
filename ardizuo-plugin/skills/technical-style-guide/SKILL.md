# 📖 Technical Style Guide

This is an original local development-focused adapter, not an official third-party skill.

Write for the actual technical reader. Use short, concrete sentences, informative headings and explicit prerequisites. Define terms where needed. Provide tested commands and correct assumptions. Eliminate unnecessary jargon and claims not backed by evidence. This original guide does not reproduce a copyrighted book.

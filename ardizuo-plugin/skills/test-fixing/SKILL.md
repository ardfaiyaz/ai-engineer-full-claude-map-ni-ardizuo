# 🛠️ Test Fixing

This is an original local development-focused adapter, not an official third-party skill.

Run the smallest failing test. Distinguish incorrect test expectations from real application defects. Trace the failing assertion to its source. Make the smallest justified repair. Rerun the specific test, then relevant suites. Do not weaken tests to make them pass.

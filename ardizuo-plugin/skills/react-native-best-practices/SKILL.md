# React Native Best Practices

This is an original local development-focused adapter, not an official third-party skill.

Inspect the actual React Native and Expo versions. Consider list virtualization, rendering cost, stable keys, touch targets, navigation, device permission boundaries, platform differences and offline behavior. Use project linter, typecheck and available device tests. Do not change dependency versions without approval.

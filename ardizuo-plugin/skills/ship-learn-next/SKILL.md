# Ship Learn Next

This is an original local development-focused adapter, not an official third-party skill.

Use completion-mandate.md. Check tests, lint, typechecks, build and review evidence only when run. Separate completed work, unverified checks, blockers, risks and follow-up. Suggest a concise vault note, but write only after explicit approval. Never auto-commit, push or deploy.

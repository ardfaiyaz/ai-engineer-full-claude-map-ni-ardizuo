This is an original local development-focused adapter, not an official third-party skill.

Respect the project tsconfig and lint rules. Prefer explicit, narrow types over any. Keep public APIs stable. Avoid duplicated code and unexplained abstractions. Review error handling, async boundaries, React effects and unnecessary state. Check typecheck, lint and appropriate tests. Report evidence before proposing refactors.

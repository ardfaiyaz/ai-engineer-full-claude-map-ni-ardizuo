# Optional local Claude Map dashboard

The working author's dashboard is a customized local Claude Map with developer stages, layered capability inventory and status coloring. **This repository does not yet package that tested customization.** Before release, review the local patch source, pin a compatible upstream Claude Map version, preserve upstream license and attribution, test sensitive output sanitization, and keep the web server bound to localhost. Never publish tokens, raw MCP headers, env data or `.claude.json` in dashboard endpoints.
